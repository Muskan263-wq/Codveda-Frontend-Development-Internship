# Responsive UI with Tailwind CSS

## 📌 Project Overview
This project is a **responsive user interface** developed as **Task 3** of the **Level 2** of the **Codveda Frontend Development Internship**. The interface is built using **Tailwind CSS** and follows modern UI/UX principles with a customized design system, ensuring responsiveness, accessibility, and a consistent visual experience across all devices.

## ✨ Features
- Fully responsive design for mobile, tablet, and desktop
- Built using Tailwind CSS utility classes
- Customized color palette and typography
- Modern and clean user interface
- Reusable UI components
- Responsive navigation bar
- Hero section with engaging layout
- Services and portfolio sections
- Contact section with footer
- Smooth hover effects and transitions
- Accessible and user-friendly design

## 🛠️ Technologies Used
- HTML5
- Tailwind CSS
- JavaScript
