# Portfolio Performance Optimization

## 📌 Project Overview

This project focuses on optimizing the performance of my **Optimization of personal portfolio website** as **Task 2** of the **Level 3** of the **CodVeda Frontend Development Internship**. Performance improvements were implemented using **Google Lighthouse** recommendations to enhance loading speed, accessibility, SEO, and overall user experience.

## ✨ Performance Optimizations

- Optimized images using the **WebP** format
- Implemented **lazy loading** for images
- Minified CSS and JavaScript files
- Reduced render-blocking resources
- Improved loading speed and interactivity
- Optimized asset delivery for better performance
- Enhanced responsive design across devices
- Improved accessibility and SEO score
- Achieved a high Google Lighthouse Performance score

## 🛠️ Technologies & Tools Used

- HTML5
- CSS3
- JavaScript
- Google Lighthouse
- WebP Image Format
- Git & GitHub
