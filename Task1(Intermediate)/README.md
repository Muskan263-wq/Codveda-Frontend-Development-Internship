# Single Page Application (SPA)

## 📌 Project Overview

This project is a **Single Page Application (SPA)** developed as **Task 1** of the **Level 2** of the **Codveda Frontend Development Internship**. The application is built using **React.js** and **React Router**, providing seamless navigation between multiple pages without full page reloads. It offers a fast, responsive, and user-friendly experience.

## ✨ Features

- Single Page Application (SPA)
- Built with React.js
- Smooth navigation using React Router
- Home, About, and Contact pages
- State management using React Context API
- Responsive design for all screen sizes
- Fast page transitions without reloads
- Modern and clean user interface
- Reusable React components
- Optimized performance

## 🛠️ Technologies Used

- React.js
- React Router DOM
- HTML5
- CSS3
- JavaScript (ES6)
- Vite
- Git & GitHub

1. Clone the repository

```bash
git clone https://github.com/your-username/your-repository.git
```

2. Navigate to the project directory

```bash

```

3. Install dependencies

```bash

```

4. Run the development server

```bash

```

