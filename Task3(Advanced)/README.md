# Advanced Animations with GSAP

## 📌 Project Overview

This project demonstrates **advanced web animations** developed as **Task 3** of the **Level 3** of the **CodVeda Frontend Development Internship**. The website uses **GSAP (GreenSock Animation Platform)** to create smooth, interactive, and high-performance animations that enhance user engagement while maintaining responsiveness and accessibility.

## ✨ Features

- Smooth GSAP-powered animations
- Scroll-triggered animations
- Interactive hover effects
- Timeline-based animation sequences
- Responsive design for all screen sizes
- Optimized animation performance
- Modern and engaging user interface
- Accessible animations that do not affect usability
- Lightweight and fast-loading experience

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- GSAP (GreenSock Animation Platform)
